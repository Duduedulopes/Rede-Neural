# 30/08/2026 — Ligado nos dois sistemas de verdade

## A descoberta que evitou guardar senha em disco

Eu ia pedir usuario e senha de admin para ler o estoque, porque
`/api/products/low-stock` tem `[Authorize(Roles = "Admin")]`.

Antes disso fui olhar o `ProductsController.cs`:

```csharp
[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase     // <- SEM [Authorize] na classe
{
    [Authorize(Roles = "Admin")] [HttpPost]  ...     // so os de ESCRITA
    [HttpGet] public async Task<...> GetAll(...)     // <- ANONIMO
```

E o `ProductResponse` do GetAll ja traz `stockQuantity`,
`minimumStockThreshold` e `isLowStock`.

    O endpoint que exige senha entrega uma LISTA FILTRADA de algo que o
    endpoint anonimo ja entrega inteiro.

Entao o monitor pega tudo por `/api/products` e filtra os de baixa aqui. Uma
credencial a menos guardada em disco, um pedido a menos na rede, e um lugar
a menos para vazar.

    Ler o codigo antes de pedir a senha economizou a senha.

## Cada coisa no seu ritmo

O painel atualiza a cada 700 ms, mas nem tudo muda nesse ritmo:

```
/api/sessions/current-open    0,8 s     muda a cada gesto do cliente
/api/sessions/pending-entry   3,0 s
/api/products                 6,0 s     muda quando alguem cadastra algo
/api/categories              30,0 s
```

Pedir os quatro a cada 700 ms castigaria a API sem motivo. Cada endpoint
guarda o proprio valor ate vencer.

## O DEFEITO QUE SO APARECEU NO TESTE AO VIVO

A faixa de GRAVACAO continuava visivel com o sistema AO VIVO.

Causa: `hidden` e um atributo com regra padrao do navegador, e QUALQUER
seletor de classe com `display` a vence. `.faixa-gravacao{display:flex}`
ganhava de `[hidden]`.

Servida pelo artifact isso nao aparecia — o esqueleto de la ja traz
`[hidden]{display:none!important}`. Servida pelo `servidor.py`, nao traz.

    A mesma pagina, dois hospedeiros, um comportamento diferente. E o
    defeito era a mentira exatamente ao contrario da que a faixa existe
    para evitar.

Conserto: a linha `[hidden]{display:none!important}` no meu proprio CSS, e
nao no de quem hospeda. Testado nos dois modos:

```
AO VIVO   hidden=true   visivel=false
GRAVACAO  hidden=false  visivel=true
```
