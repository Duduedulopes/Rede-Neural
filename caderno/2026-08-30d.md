# 30/08/2026 — O monitor do gerente

Um programa que roda sozinho e voce assiste. Nao e o explorador de ontem.

## As duas fontes, uma interface

    ao vivo       servidor local le o SO Espacial e chama a WebApi do SmartGo
    reproducao    1.400 eventos reais gravados, na ordem original

A MESMA pagina. O painel diz no topo qual modo esta valendo, e cada fonte
acende o proprio LED. Se o SO Espacial nao esta no ar, o painel nao inventa
pessoas — ele diz que aquela fonte esta fora.

    Abster-se e resultado de primeira classe. Vale para camera e vale para
    fonte de dados.

## Por que precisa de servidor

Um HTML aberto com `file://`, ou publicado na web, NAO pode ler arquivos do
disco nem chamar `localhost`. O navegador proibe, e com razao — senao
qualquer site leria os meus arquivos.

O servidor local e a ponte. Biblioteca padrao apenas, sem instalar nada:

    python monitor/servidor.py     ->  http://localhost:8760

## Divisao cronologica, nao aleatoria

Dividi treino e teste por TEMPO, e nao embaralhando.

Eventos vizinhos no tempo sao quase identicos — o mesmo braco mudando de
estado tres vezes em dois segundos. Embaralhando, primos do treino cairiam
no teste, a nota subiria e nao significaria nada.

## A conferencia entre Python e JavaScript, e o que ela achou

O extrator de caracteristicas existe duas vezes: em `monitor/caracteristicas.py`
e portado no painel. Se divergirem, o painel mostra uma coisa e o treino
aprendeu outra — o defeito mais dificil de achar num sistema assim.

Conferi os 300 primeiros eventos nos dois:

```
soma total          Python 880,583942     JS 880,583940
soma por coluna     iguais ate a 5a casa em todas as 38
valores nao-zero    Python 1.458          JS 1.416     <- 42 de diferenca
```

Os 42 estao TODOS na coluna `silencio_antes`. Causa encontrada:

    `Date.parse` do JavaScript tem resolucao de MILISSEGUNDO.
    `datetime.fromisoformat` do Python tem resolucao de MICROSSEGUNDO.

Ha 66 pares de eventos com menos de 1 ms de intervalo no trecho. Para o
Python o intervalo existe; para o JavaScript ele e zero.

Impacto real: desprezivel — a caracteristica e `silencio/30`, entao a
diferenca fica na quinta casa. Mas so descobri porque conferi, e essa e a
classe de divergencia silenciosa que estraga um sistema de duas linguagens.
